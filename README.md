# 📇 Agenda de Contatos

> **Projeto Didático:** Desenvolvido em Java para acompanhar a evolução dos conceitos práticos da disciplina de **Programação Orientada a Objetos (POO)**.

---

## 🎯 Objetivo

Construir uma aplicação completa de **Agenda de Contatos**, iniciando com uma solução procedural simples e evoluindo de forma incremental até uma estrutura robusta com Programação Orientada a Objetos, Padrões de Projeto (MVC, DAO), Interface Gráfica e Persistência de Dados.

---

## 🚀 Evolução do Projeto

O desenvolvimento é focado no aprendizado gradual. A cada nova versão, são introduzidos novos conceitos, estruturas e melhorias arquiteturais sobre o código anterior.

### 📍 `v0.0.0` — Programação Procedural Básica

Primeira versão da agenda, focada na sintaxe e nos fundamentos da linguagem Java.

* **Estrutura:**
  * Classe única: `Principal`
  * Todo o código centralizado dentro do método `main()`
  * Armazenamento temporário de apenas **um contato** (um novo registro substitui o anterior)
  * Manipulação de variáveis simples: `nome`, `celular` e `email`

* **Recursos e Estruturas Utilizadas:**
  * Menu interativo via console
  * Leitura de dados com `Scanner`
  * Estruturas de decisão (`if-else`, `switch-case`)
  * Estruturas de repetição (`while`)

* **Funcionalidades:**
  * ➕ Adicionar contato
  * 📋 Listar contato
  * 🔍 Procurar contato
  * ❌ Excluir contato
  * 🚪 Sair
